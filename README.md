# n8n-nodes-intelligentdata

n8n community node for the [Intelligent Data API](https://portal.smartvmapi.com) by apexanalytix.

## Installation

In your n8n instance, go to **Settings > Community Nodes** and install:

```
n8n-nodes-intelligentdata
```

## Credentials

Add an **Intelligent Data API** credential with your API key (starts with `svm`).

## Available Operations

- **Address Validation** — Validate and standardize postal addresses worldwide
- **Tax ID Validation** — Validate tax identification numbers (100+ countries)
- **Bank Account Validation** — Verify bank account details (IBAN, routing numbers)
- **Business Registration Lookup** — Look up official company registration data
- **Sanctions Screening** — Screen against global sanctions lists (OFAC, EU, UN)
- **Disqualified Directors Check** — Check for disqualified directors

## Getting an API Key

1. Sign up at [portal.smartvmapi.com](https://portal.smartvmapi.com/auth/register)
2. Navigate to Dashboard > API Keys
3. Copy your API key
